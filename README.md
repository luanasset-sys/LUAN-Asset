# Equity Research HQ

One command — `python hq.py TICKER` — analyzes a stock through **four independent
lenses**, writes the results to Airtable and a Google Sheet, and prints a
one-page scorecard that flags where the lenses **agree vs disagree**.

> **Decision-support only — not financial advice.** Generated by automated
> models; verify before acting.

## The four lenses

| Lens | Source | What it answers |
|------|--------|-----------------|
| **Fundamental** | SEC EDGAR | DCF (bull/base/bear) + P/E, EV/EBITDA, EV/Sales vs the stock's *own* 5y history, quality (margins, ROIC, FCF conversion, net debt/EBITDA), growth → fair-value range + verdict |
| **Technical** | yfinance | 50/200 MAs (golden/death cross), RSI, 3/6/12-mo returns, realized vol, max drawdown, relative strength vs SPY + sector ETF → "what path is it on" |
| **Markov regime** | yfinance | Weekly Up/Flat/Down × hi/lo-vol states → transition matrix, current state, next-period distribution, long-run steady state. **Regime framing, not prediction.** |
| **Macro / government** | FRED + Claude web search | Fed/rates posture + legislation, regulation, tariffs, export controls relevant to energy / data centers / AI infra → tailwind/headwind, cited & dated |

The scorecard never collapses to a single buy/sell number — it shows the four
verdicts side by side and an **agreement map**. The disagreement is the signal.

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env      # then fill in the values
```

Fill `.env` (see `.env.example` for links):

- `SEC_USER_AGENT` — your name + email (EDGAR requires it; no key)
- `FRED_API_KEY` — free from fredaccount.stlouisfed.org
- `ANTHROPIC_API_KEY` — from console.anthropic.com (macro web search + polish)
- `AIRTABLE_API_KEY` — a PAT with `data.records:read/write` + `schema.bases:read/write`
  scoped to the base; `AIRTABLE_BASE_ID` is pre-filled (`appL5ByzBTesKLEWo`)
- `GOOGLE_SA_JSON` + `GOOGLE_SHEET_ID` — see below (optional; `--no-sheets` to skip)

## Usage

```bash
python hq.py NVDA                 # full run: 4 lenses → Airtable + Sheet → scorecard
python hq.py XOM --dry-run        # analyze + print only, no writes
python hq.py VST --no-sheets      # skip the Google Sheet mirror
python hq.py CEG --no-llm         # free mode: skip Anthropic (macro = FRED only)

# Watchlist mode — analyze many names, get a side-by-side comparison table:
python hq.py --watchlist NVDA,VST,CEG,XOM
python hq.py --watchlist tickers.txt        # one ticker per line ('#' comments ok)
python hq.py --watchlist tickers.txt --full # also print each full scorecard
```

Each watchlist ticker still writes its own rows to Airtable/Sheets and its own
`runs/` snapshot; the comparison table at the end flags which names have
cross-lens **conflict** (the disagreement is the signal).

Every run also drops a full JSON snapshot in `runs/` — raw data + timestamps, so
everything is backtestable later.

## Interactive dashboard

Prefer to *poke at the numbers* instead of reading a text summary? There's a
browser dashboard:

```bash
pip install -r requirements.txt    # (includes streamlit)
streamlit run app.py
```

Your browser opens a dashboard where you can:
- enter any ticker and see the four-lens scorecard + agreement banner;
- **drive the DCF with sliders** (growth, WACC, terminal growth, horizon) and watch
  fair value recompute live, with a growth × discount sensitivity grid;
- read **what the market is pricing in** — a *reverse DCF* that solves for the FCF
  growth today's price implies (far more useful than a single "target");
- see **why the valuation is what it is** — a transparent year-by-year breakdown of
  projected cash flows, the EV→equity→per-share bridge, how much value is terminal,
  and **backlog / remaining performance obligations** where reported;
- get an optional **AI-written plain-English explanation** of the valuation (needs key);
- open the **Macro & News tab** — live Fed/rates, policy, tariffs/export-controls,
  active wars/geopolitics, and dated headlines tied to the stock's forward outlook
  (needs the Anthropic key);
- browse full per-year financials & quality ratios, price/MA & drawdown charts,
  today's valuation vs the stock's own 5-year range, and a side-by-side comparison;
- optionally save the run to Airtable with one button.

> The valuation defaults are intentionally market-realistic (8.5% discount, 3% terminal).
> A simple DCF on free annual data is best read for the *reverse* signal (what's priced
> in) and *relative* sensitivity — not as a literal price target.

The dashboard uses the same lenses and free data sources as the CLI.

## Google Sheets setup (click-by-click)

The standalone script writes to Sheets via a **service account** (no browser
login needed at runtime).

**A. Create the service account + key**
1. Go to <https://console.cloud.google.com/> and create (or pick) a project.
2. **APIs & Services → Library** → search **Google Sheets API** → **Enable**.
   (Also enable **Google Drive API** if you want the script to create new sheets.)
3. **APIs & Services → Credentials → Create credentials → Service account**.
   Give it a name (e.g. `research-hq`), click **Create and continue**, skip the
   optional role grants, **Done**.
4. Click the new service account → **Keys** tab → **Add key → Create new key →
   JSON → Create**. A `.json` file downloads. Save it in this folder as
   `service_account.json` (already gitignored) and set `GOOGLE_SA_JSON` to its path.
5. Open the JSON and copy the `client_email` value (looks like
   `research-hq@your-project.iam.gserviceaccount.com`).

**B. Create the sheet and share it**
6. Create a blank Google Sheet in your own Drive (so it's easy to open on your
   phone). Name it e.g. "Equity Research HQ".
7. Click **Share**, paste the service account's `client_email`, give it **Editor**,
   send/confirm.
8. Copy the Sheet ID from its URL —
   `https://docs.google.com/spreadsheets/d/`**`THIS_IS_THE_ID`**`/edit` — and set
   `GOOGLE_SHEET_ID` in `.env`.

On first run the script creates a **Scorecard** tab with a header row and appends
one row per run. Open the sheet on your phone to check results anywhere.

## Notes

- **Free-first.** EDGAR + yfinance + FRED carry the quantitative work; Anthropic
  powers only the macro web search and optional prose polish. Run `--no-llm` to
  stay fully free (macro falls back to the FRED rates backdrop).
- **Markov is regime framing,** not a forecast — labeled as such in the output.
  A clean hook is in place to upgrade to a Hidden Markov Model (`hmmlearn`) later.
- See `CLAUDE.md` for architecture and the standing design rules.
